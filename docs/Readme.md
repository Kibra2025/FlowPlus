# FlowPlus documentation

FlowPlus is an independent Deskflow fork with experimental LocalSend protocol file transfer integration. Start with the [project README](../README.md), [architecture](ARCHITECTURE.md), [build guide](dev/build.md), and [testing checklist](TESTING.md).

See the [licensing guide](LICENSING.md) for the inherited GPL/OpenSSL terms,
file-level licenses and redistribution notes. The README includes matching
downloads, macOS setup steps and a comparison of FlowPlus's additions to Deskflow.

The [configuration reference](user/configuration.md) documents inherited input sharing settings. Protocol names and historical source identifiers retain their upstream meaning; file dragging requires FlowPlus at both endpoints.
